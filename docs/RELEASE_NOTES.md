# Release Notes

## v2.0.0 — 2026-10-12

### ✨ 新增
- **USB 连接模式**：插上数据线自动识别并投屏（`自动（USB 优先）/ 仅 USB / 仅无线` 三档），解决电脑无法使用无线调试（如仅能连手机热点）的场景
- **全新主界面**：启动即显示深色圆角窗口 —— 设备状态卡片、连接方式、窗口宽度/置顶/无边框、一键开始/停止投屏
- **全新图标**：蓝紫渐变 + 手机投屏 + 在线指示（替换原默认图标）
- 单实例保护，避免重复启动

### 🎨 优化
- 托盘菜单完善（显示主界面 / 开始 / 停止 / 配置手机键盘布局 / 退出）
- 界面全面深色主题化

### 📦 说明
- 安装包含 scrcpy 4.1 运行时与 ADB；程序未签名，首次运行若杀毒软件提示请选择「允许/信任」

## v1.1.0 — 2026-10-11

### 🐛 修复
- 反向键盘中文输入不出字：scrcpy 改用 `--keyboard=uhid`（模拟物理 HID 键盘，支持手机 IME）
- 托盘新增「配置手机键盘布局」（调起 `HARD_KEYBOARD_SETTINGS`，首次选 English(US) 一次配好）

## v1.0.0 — 2026-10-11

### 🚀 首个版本
- 托盘版无线投屏（scrcpy 4.1）：无边框小窗、置顶、防锁屏
- 配置：`conn_addr`（无线 IP:端口）、窗口宽度、置顶、无边框
