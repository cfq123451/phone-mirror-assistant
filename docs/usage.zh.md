# 手机投屏助手 · 使用说明

## 启动
双击 `手机投屏.exe` 或 `启动手机投屏.bat`。启动即显示主界面；关闭窗口后驻留系统托盘。

## USB 连接（推荐）
1. 手机：设置 → 关于手机 → 连点「版本号」7 次开启开发者模式 → 打开「USB 调试」
2. 数据线插电脑后置 USB 口（避免前置面板与集线器）
3. 手机上点「允许 USB 调试」（建议勾选「始终允许」）
4. 软件自动识别设备并开始投屏（状态卡片显示 `USB · 序列号 · 投屏运行中`）

## 无线连接（备用）
1. 手机开启「无线调试」，用配对码配对一次
2. 把无线调试主界面的 `IP:端口` 填入「无线地址」
3. 连接方式选「仅无线」或「自动」
> 电脑连手机热点时，多数手机拒绝无线调试 —— USB 是稳定方案。

## 主界面功能
- **连接方式**：自动（USB 优先）/ 仅 USB / 仅无线
- **窗口宽度**：300 / 400 / 600 / 800 / 1200，可勾选「窗口置顶」「无边框」
- **开始投屏 / 停止投屏**：手动控制
- **配置手机键盘布局**：解决反向控制打字不出字（首次选 English(US)）
- **关闭窗口** = 最小化到托盘；右键托盘图标：显示主界面 / 开始 / 停止 / 退出

## 常见问题
- **识别不到设备**：换一根能传数据的线（很多线只能充电）；USB 模式改成「传输文件 / MTP」；设备管理器有黄色感叹号用「驱动总裁」装驱动
- **杀毒软件提示**：本软件未签名，首次运行若火绒等提示，点「允许 / 信任」
- **还原旧版**：文件夹内「手机投屏-旧版备份.exe」改名替换即可
